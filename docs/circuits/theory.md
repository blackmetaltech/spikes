# Theory wing: dynamics, rates, memory, tuning

Levels in `engine/src/tasks/` on the Bestiary scaffolding (`bestiary_a.h`, plus `theory.h` for the levels that read a cell's own parameters). Reference circuits: `circuits/*.json`, generated by `circuits/tools/gen_theory.py`. Cheap circuits that must fail: `engine/tests/cheap_rows_f.inc`; contract and reference tests: `engine/tests/tasks_theory_test.cpp`. Design and what is simplified: `docs/DESIGN-THEORY.md`.

## Dynamics (`dynamics`)

| Level | Teaches | Mechanism the check demands | Reference |
|---|---|---|---|
| `d_class` | class I and class II excitability | a two-variable cell whose resting state, read from its phase plane, is lost as a resonant focus (Hopf), not a node (saddle-node) | 1 Izhikevich cell (a 0.1, b 0.26, c -65, d 2) |
| `d_phasic` | a stable fixed point that survives the current: phasic firing | a stable fixed point at the held current; behaviour: spikes at the step, none later | 1 Izhikevich cell (a 0.02, b 0.25, c -65, d 6), step 0.5 |
| `d_switch` | bistability: one cell, two stable states | a stable fixed point at the holding current, all three sensors reaching the cell; behaviour: on after `set`, off after `reset`, twice | 1 Izhikevich cell (a 0.02, b 0.2, c -50, d 0), hold 2.5 |

* The staircase of `d_class` is scaled to the cell: 70 % to 130 % of the current at which its own resting state is lost (`theory::onset`), so the sensor weight cannot turn a slowly-starting cell into an abrupt one (tested at weights x0.1 and x30).
* The resonance threshold of `d_class` (the damped oscillation of the resting state must be at least 15 Hz) is a game value that separates the Izhikevich resonator and fast-spiking presets from the regular-spiking default, whose rest is a nearly degenerate spiral (a Bogdanov-Takens neighbourhood).
* `d_switch`: the `reset` sensor carries a negative current (the level is scaled by -1 in the task), so its weight stays positive in the lab; the window of holding currents that works for the reference is about 1.5 to 3.5 (the cell fires on its own from 4).
* Izhikevich cells start at their resting fixed point (`rest_state`), not at NEST's U = 0.
